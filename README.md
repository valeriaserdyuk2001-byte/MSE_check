# Перечень обследований для направления на МСЭ

Браузерное приложение для подбора обследований по коду МКБ-10 для лиц в возрасте 18 лет и старше на основании раздела I Перечня, утвержденного приказом Минтруда России и Минздрава России от 16.05.2024 № 259н/238н.

## Что делает приложение

- принимает один код МКБ-10;
- учитывает одновременно общие диапазоны и более точные рубрики МКБ-10;
- позволяет выбрать первичное или повторное направление;
- при указанной предполагаемой дате МСЭ рассчитывает самую раннюю дату, с которой обследование укладывается в установленный срок давности;
- если дата МСЭ не указана, колонка «Годен с» не показывается;
- разделяет основные и дополнительные обследования;
- отображает первый вариант альтернативы как основную строку, а остальные — как вложенные подварианты «ИЛИ»;
- для основных альтернатив требует выбрать один вариант перед печатью;
- позволяет исключать из печати отдельные дополнительные обследования;
- для дополнительных альтернатив позволяет либо выбрать один вариант, либо убрать из печати всю группу;
- формирует таблицу с отметкой о выполнении и поддерживает печать.

## Файлы

- `index.html` — интерфейс;
- `style.css` — оформление и печать;
- `app.js` — поиск по МКБ-10, сроки и формирование списка;
- `mse_data.json` — подготовленная база раздела I;
- `alternative_groups.json` — группы альтернативных обследований, восстановленные из структуры раздела I приказа;
- `mse_data_adults.csv` — табличная копия подготовленной взрослой базы.

## Локальный запуск

Открытие `index.html` напрямую через `file://` может блокировать загрузку JSON. Запустите простой HTTP-сервер:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000/`.

## GitHub Pages

Загрузите файлы в репозиторий и включите: `Settings → Pages → Deploy from branch → main → /(root)`.

## Альтернативные обследования

Если в приказе несколько медицинских услуг связаны отдельной строкой «или», первый вариант показывается как обычная основная строка, а следующие — как вложенные подварианты с подписью `ИЛИ — Вариант 2`, `ИЛИ — Вариант 3` и т. д.

Перед печатью в каждом основном блоке альтернатив нужно выбрать один вариант с помощью переключателя «Печатать этот вариант». В распечатку попадут все строки выбранного варианта, а остальные варианты этой группы будут скрыты. Если один вариант состоит из нескольких медицинских услуг, они сохраняются как единый вариант и печатаются вместе.

Для дополнительной альтернативной группы можно выбрать один вариант либо отметить «Не печатать эту группу», если обследование по показаниям не требуется. Обычные дополнительные обследования можно исключать из печати по одному с помощью флажка «Не печатать».

Связки `и (или)` внутри текста медицинских показаний автоматически не превращаются в правило «выбрать одно», поскольку это уже иная логика приказа и она зависит от клинических условий.
