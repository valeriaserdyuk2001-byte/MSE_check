# Перечень обследований для направления на МСЭ

Браузерное приложение для подбора обследований по коду МКБ-10 для лиц в возрасте 18 лет и старше на основании раздела I Перечня, утвержденного приказом Минтруда России и Минздрава России от 16.05.2024 № 259н/238н.

## Что делает приложение

- принимает один код МКБ-10;
- учитывает одновременно общие диапазоны и более точные рубрики МКБ-10;
- позволяет выбрать первичное или повторное направление;
- при указанной предполагаемой дате МСЭ рассчитывает самую раннюю дату, с которой обследование укладывается в установленный срок давности;
- если дата МСЭ не указана, колонка «Годен с» не показывается;
- разделяет основные и дополнительные обследования;
- отображает первый вариант альтернативы как основную строку, а остальные — как вложенные подварианты «ИЛИ»;
- у обычных основных обследований флажок «Печатать» включен по умолчанию, но его можно снять;
- у обычных дополнительных обследований флажок «Печатать» выключен по умолчанию — в печать попадают только выбранные пользователем пункты;
- в основных блоках «ИЛИ» печать группы включена по умолчанию и по умолчанию выбран первый вариант; можно выбрать другой вариант или убрать всю группу из печати;
- в дополнительных блоках «ИЛИ» печать группы выключена по умолчанию; при необходимости группу можно включить и выбрать один вариант;
- формирует таблицу с отметкой о выполнении и поддерживает печать.

## Файлы

- `index.html` — интерфейс;
- `style.css` — оформление и печать;
- `app.js` — поиск по МКБ-10, сроки и формирование списка;
- `mse_data.json` — подготовленная база раздела I;
- `alternative_groups.json` — группы альтернативных обследований, восстановленные из структуры раздела I приказа;
- `mse_data_adults.csv` — табличная копия подготовленной взрослой базы.

## Локальный запуск

Открытие `index.html` напрямую через `file://` может блокировать загрузку JSON. Запустите простой HTTP-сервер:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000/`.

## GitHub Pages

## Настройка печати

У каждого обычного обследования есть флажок `Печатать`:

- **основные обследования** отмечены по умолчанию;
- **дополнительные обследования** по умолчанию не отмечены.

Таким образом, перед печатью основные пункты уже готовы к распечатке, но условный или ненужный основной пункт можно снять. Из дополнительных обследований пользователь отмечает только те, которые действительно нужны по показаниям.

Если в приказе несколько медицинских услуг связаны отдельной строкой «или», первый вариант показывается как обычная строка, а следующие — как вложенные подварианты `ИЛИ — Вариант 2`, `ИЛИ — Вариант 3` и т. д.

У такого блока две настройки:

1. `Печатать эту группу` — определяет, нужна ли группа вообще. Для основных групп флажок включен по умолчанию, для дополнительных — выключен.
2. `Выбрать этот вариант` — определяет, какой один вариант попадет в распечатку. Первый вариант выбран по умолчанию.

Если печать группы отключена, ни один ее вариант не печатается. Если включена — печатается только выбранный вариант. Если один вариант состоит из нескольких медицинских услуг, они сохраняются как единый вариант и печатаются вместе.

Если в дополнительном разделе не выбрано ни одного пункта, заголовок «Дополнительные обследования» также не выводится в распечатке.

Связки `и (или)` внутри текста медицинских показаний автоматически не превращаются в правило «выбрать одно», поскольку это иная логика приказа и она зависит от клинических условий.
